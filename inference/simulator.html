Serving-engine simulator

One replica of Llama-3-70B in BF16, tensor-parallel over four H100s. Requests arrive by a Poisson process with heavy-tailed prompt and output lengths, the scheduler batches them one iteration at a time, the paged KV block pool allocates and frees, and three meters move. A step costs a fixed weight read (14 ms, paid once however many sequences ride on it), a per-sequence KV read proportional to context length, and a compute term that only binds once the step's token count passes B_crit. Every constant is derived from the course's reference numbers, so the meters read like a real machine and the knobs move them for the real reasons. Start with the numbered scenarios.
